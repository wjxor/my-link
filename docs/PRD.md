# 제품 요구사항 정의서 (PRD) - 마이링크(MyLink)

## 1. 프로젝트 개요
- **프로젝트명**: 마이링크 (MyLink)
- **목적**: 개발자 및 크리에이터가 자신의 포트폴리오, 소셜 미디어, 블로그, 프로젝트 링크 등을 하나의 페이지로 모아서 공유할 수 있는 링크 모음 서비스 구축.
- **대상 사용자**: 
  - 깃허브, 기술 블로그(벨로그, 티스토리 등), 포트폴리오 등 공유할 링크가 많은 **개발자**
  - 유튜브, 인스타그램 등 여러 채널을 운영하는 **크리에이터**
- **주요 기술 스택**: 
  - Frontend: React / Next.js 등 (shadcn/ui 기반 컴포넌트 디자인 시스템 활용)
  - Backend/Auth: Firebase (구글 소셜 로그인 전용)

## 3. 기능 상세 설명

### 3.1. 인증 및 계정 (Auth)
- **구글 소셜 로그인**: Firebase Authentication을 사용하여 구글 계정으로만 간편하게 가입 및 로그인을 진행합니다. 별도의 이메일/비밀번호 가입은 받지 않아 사용자 진입 장벽을 낮춥니다.
- **초기 프로필 설정**: 구글 로그인 직후, 프로필 정보를 설정하게 됩니다.
  - **displayName (URL 슬러그)**: 사용자의 구글 지메일 주소에서 아이디 부분(`@` 앞부분)을 추출하여 초기 기본값으로 자동 설정합니다. 이 값이 개인 페이지의 고유 URL 슬러그로 사용됩니다.
  - **username (실제 이름)**: 프로필 화면 상단에 노출되는 실제 사용자 이름입니다.

### 3.2. 데이터베이스 모델링 (NoSQL - Firestore)
서비스에 필요한 데이터를 NoSQL 기반의 Firebase Firestore에 다음과 같이 구조화합니다.

```text
📦 Collection: users
 ┗ 📜 Document: {uid} (Firebase Auth에서 발급받은 사용자 고유 ID)
    ┣ 🔤 displayName  : string    // URL 슬러그로 사용되는 닉네임 (지메일 ID 기반, 중복 불가)
    ┣ 🔤 username     : string    // 화면 프로필 상단에 노출되는 실제 이름
    ┣ 🔤 bio          : string    // 프로필 한줄 소개글
    ┣ 🔢 visitorCount : number    // 누적 방문자 수 통계 (기본값: 0)
    ┣ 🕒 createdAt    : timestamp // 계정 생성 일시
    ┣ 🕒 updatedAt    : timestamp // 프로필 마지막 수정 일시
    ┃
    ┗ 📦 Sub-collection: links (해당 사용자가 생성한 링크 목록)
       ┗ 📜 Document: {auto-generated-id} (자동 생성되는 고유 ID)
          ┣ 🔤 title      : string    // 링크 제목
          ┣ 🔤 url        : string    // 실제 연결될 주소
          ┣ 🔢 clickCount : number    // 개별 링크 클릭 조회수 (추후 추가 기능용, 기본값: 0)
          ┣ 🕒 createdAt  : timestamp // 링크 생성 일시 (리스트 정렬 기준으로 사용)
          ┗ 🕒 updatedAt  : timestamp // 링크 수정 일시
```

- **식별 및 조회**: `mylink.com/[displayName]` 접속 시 `users` 컬렉션에서 `displayName`을 URL 슬러그 조건으로 사용하여 데이터를 조회합니다. (지메일 아이디를 기본값으로 쓰더라도 가입 시점에 중복 확인 절차가 필수적입니다.)
- **정렬 방식**: 링크에 별도의 커스텀 순서 필드를 두지 않으며, `links` 서브 컬렉션의 데이터를 불러올 때 `createdAt` 필드를 기준으로 정렬하여 렌더링합니다.
- **파비콘 비저장**: 파비콘 이미지는 DB에 저장하지 않으며, 클라이언트 렌더링 단계에서 해당 링크의 `url`을 기반으로 구글 파비콘 API를 동적으로 호출하여 표시합니다.

### 3.3. 프로필 관리
- **고유 URL 부여**: `https://서비스주소/[displayName]` 형태의 개인 프로필 링크를 생성하여 제공합니다.
- **프로필 에디터**: 
  - **이미지 업로드 제한**: 별도의 사용자 프로필 이미지 업로드 기능은 제공하지 않습니다.
  - **프로필 정보 수정**: 프로필 화면에 노출되는 실제 이름(username)과 짧은 소개글(Bio), 그리고 URL로 사용되는 닉네임(displayName)을 언제든지 사용자가 직접 수정할 수 있습니다. (단, 닉네임 수정 시 접속 URL이 함께 변경된다는 점을 사용자에게 명확히 안내해야 합니다.)

### 3.4. 링크 관리 및 대시보드
- **링크 인라인 편집(Inline Edit)**: 새로운 링크를 추가할 수 있으며, 생성된 링크의 제목(Title)과 URL을 수정할 때는 별도의 상세 페이지나 모달을 띄우지 않고, 화면 상의 리스트에서 텍스트를 바로 클릭해 수정하는 인라인 편집 방식을 채택합니다.
- **파비콘(Favicon) 아이콘 적용**: 사용자가 링크 URL을 입력/수정하면 구글 파비콘 API(`https://www.google.com/s2/favicons?domain=...`)를 호출하여 해당 웹사이트의 파비콘 이미지를 자동으로 가져와 링크 항목의 아이콘으로 사용합니다.

### 3.5. 통계
- **방문자 통계**: 프로필 페이지에 접속한 방문자의 통계 데이터를 대시보드에서 기본적으로 제공합니다.
- **링크 클릭 조회수 (추후 추가 예정)**: 방문자가 각 링크 항목을 클릭한 횟수를 추적하여 보여주는 기능은 향후 추가 기능으로 구현될 예정입니다.

### 3.6. 디자인 시스템 (shadcn/ui) 적용
- **일관된 UI/UX**: 버튼, 폼(Form), 텍스트 입력창 등의 모든 UI 요소는 shadcn/ui 컴포넌트를 사용하여 일관되고 모던한 디자인을 유지합니다.
- **테마 기능 제외**: 다크/라이트 모드 지원이나 색상 변경 등의 커스텀 테마 기능은 일절 배제하고, 단일 디자인으로 간결하게 서비스됩니다.

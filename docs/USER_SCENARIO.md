# 사용자 시나리오 (User Scenario) - 마이링크(MyLink)

## 1. 방문자 (Visitor): 마이링크 페이지 방문 과정

### 1.1. 정상 접속 시나리오
- 방문자는 **소유자의 프로필과 링크 목록을 확인하기 위해** 제공받은 공유 URL(`mylink.com/displayName`)로 접속한다.
- 방문자는 **페이지 로딩 시점에 서버에 접속을 기록하기 위해** 별도의 동작 없이 화면을 확인하며, 이때 DB의 방문자 통계(visitorCount)가 자동으로 1 증가한다.
- 방문자는 **소유자의 특정 소셜 미디어나 블로그로 이동하기 위해** 화면에 나열된 링크 항목 중 하나를 클릭한다.

### 1.2. 예외 및 특수 상황 시나리오 (개선점 반영)
- 방문자는 **소유자가 아직 아무런 링크를 등록하지 않은 경우 이를 인지하기 위해** "아직 등록된 링크가 없습니다"라는 빈 화면(Empty State) 안내 메시지를 확인한다.
- 방문자는 **오타 등으로 존재하지 않는 주소에 접속했을 때 당황하지 않기 위해** "존재하지 않는 페이지입니다"라는 404 에러 화면을 보고, 마이링크 메인 홈으로 돌아가는 버튼을 클릭한다.

---

## 2. 소유자 (Owner): 대시보드 및 링크 관리 과정

### 2.1. 링크 추가 시나리오
- 소유자는 **새로운 링크를 등록하기 위해** 대시보드 상단의 '링크 추가' 버튼을 클릭한다.
- 소유자는 **빠르게 링크 정보를 입력하기 위해** 리스트 상단에 즉시 생성된 빈 인라인 입력 칸에 링크 제목과 URL을 타이핑한다.
- 소유자는 **입력한 내용을 확정하고 저장하기 위해** 키보드의 `Enter` 키를 누른다.
- 소유자는 **입력한 URL의 파비콘이 정상적으로 적용되었는지 확인하기 위해** 저장 직후 링크 항목 좌측에 동적으로 나타나는 아이콘을 확인한다.
- 소유자는 **링크 추가가 성공적으로 완료되었음을 인지하기 위해** 화면 하단에 나타나는 "저장되었습니다"라는 알림(Toast) 메시지를 확인한다.

### 2.2. 링크 수정 (인라인 편집) 시나리오
- 소유자는 **기존에 등록된 링크의 제목이나 URL을 수정하기 위해** 리스트에서 변경하려는 텍스트 영역을 마우스로 직접 클릭하여 활성화(포커스)한다.
- 소유자는 **기존 내용을 지우고 새로운 텍스트로 변경하기 위해** 키보드로 수정 내용을 타이핑한다.
- 소유자는 **수정된 내용을 확정하고 저장하기 위해** 키보드의 `Enter` 키를 누른다.
- 소유자는 **수정이 성공적으로 데이터베이스에 반영되었음을 인지하기 위해** 나타나는 "수정되었습니다" 알림(Toast) 메시지를 확인한다.

### 2.3. 링크 삭제 시나리오
- 소유자는 **더 이상 노출하고 싶지 않은 링크를 지우기 위해** 해당 링크 항목 우측에 위치한 '삭제(휴지통)' 아이콘을 클릭한다.
- 소유자는 **실수로 삭제하는 것을 방지하기 위해** 화면 중앙에 나타나는 "정말 삭제하시겠습니까?" 확인 모달 창에서 '확인' 버튼을 클릭한다.
- 소유자는 **링크가 목록에서 완전히 지워졌음을 인지하기 위해** 리스트에서 항목이 사라지는 것을 보고, "삭제되었습니다" 알림(Toast) 메시지를 확인한다.

### 2.4. 비어있는 상태 (Empty State) 시나리오 (개선점 반영)
- 소유자는 **초기 가입 직후 또는 모든 링크를 삭제한 경우, 첫 행동을 유도받기 위해** 대시보드 중앙의 "첫 번째 링크를 추가해 보세요"라는 안내 메시지를 확인하고 '링크 추가' 버튼을 클릭한다.
